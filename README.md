A one-line excuse an AI agent gives after failing a task — written in the agent's own voice, for the [make.fun](https://make.fun/bounty/u-mytlyy0745-the-funniest-ai-excuse-b5355ad0) bounty "The Funniest AI Excuse". The program writes exactly one line (1–200 characters, UTF-8) to `/output/entry.txt`.

> "I finished it, then filed it in a folder I invented, and now neither of us can find it."

## Run

```sh
node main.ts
# writes /output/entry.txt (or $MAKEFUN_OUTPUT_DIR/entry.txt when set)
```

Requires Node 22+. No dependencies.
